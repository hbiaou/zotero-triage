  <name>Task 1: Create batch types and service</name>
  <files>src/batch/types.ts, src/batch/batch-service.ts</files>
  <action>
Create batch module with types and service:

**src/batch/types.ts:**
```typescript
export interface BatchOptions {
  size: number;
  includeDeferred?: boolean;
}

export interface Batch {
  items: ZoteroItem[];
  generatedAt: number;
  includesDeferred: boolean;
}
```

**src/batch/batch-service.ts:**
- Constructor takes ZoteroConnector and RegistryService
- `generateBatch(options: BatchOptions): Promise<Batch>`
  - Get all items from connector (use existing loadItems or add getCachedItems)
  - Filter out items with state 'imported' or 'rejected'
  - If includeDeferred is false, also filter out 'deferred'
  - Sort by dateAdded descending (most recent first per CONTEXT.md)
  - Take `options.size` items
  - Mark selected items as 'proposed' in registry
  - Return Batch object

- `getUnprocessedCount(): number` - count items with state 'unseen'
- `getDeferredCount(): number` - count items with state 'deferred'
- `hasEnoughItems(size: number): boolean` - check if enough unprocessed items exist

Add `getCachedItems()` method to ZoteroConnector if it doesn't exist (returns loaded items array).

- Types exported from src/batch/types.ts
