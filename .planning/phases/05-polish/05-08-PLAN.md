2. Reopen Obsidian and observe plugin load time

**Test 2: Progress Feedback**
1. Open triage view (ribbon icon or command palette)
2. Click "Generate Batch"
3. Expected: See persistent Notice with progress bar showing "Loading items..." and percentage
4. Verify: Progress updates during loading, completes with success message

**Test 3: Error Handling**
1. With Zotero OPEN (database locked), open triage view and generate batch
2. Expected: See user-friendly error "Database Temporarily Locked" with "Retry" button
3. Click "Retry" button
4. Expected: Operation retries automatically (may succeed after Zotero releases lock)
5. Verify: No raw error stack traces shown to user

**Test 4: SQLITE_BUSY Retry (requires Zotero running)**
1. Open Zotero (to lock database)
2. Generate batch in ZotBridge
3. Expected: Automatic retry with exponential backoff (check console for retry logs)
4. Close Zotero mid-retry
5. Expected: Operation succeeds after retry

**Test 5: Cross-Platform Paths (if testing on multiple platforms)**
1. Configure database path with different case (e.g., "ZOTERO.sqlite" instead of "zotero.sqlite")
2. Generate batch
3. Expected: Plugin handles path correctly despite case difference
4. Verify: No "file not found" errors

**Test 6: Memory Stability (extended session)**
1. Enable dev mode: Set NODE_ENV=development in environment
2. Generate 10-20 batches in succession
3. Check console for MemoryMonitor logs
4. Expected: Memory growth plateaus after initial batches (no monotonic increase)
5. Verify: Final memory summary shows < 100MB growth over session

**Test 7: Error Actions**
1. Rename or move Zotero database file temporarily
2. Try to generate batch
3. Expected: ErrorModal with "Database Not Found" message
4. Click "Open Settings" action
5. Expected: Settings tab opens to configure database path
6. Restore database and retry

**Test 8: Progress Cancellation**
1. Generate batch with large library (5000+ items)
2. While progress Notice is showing, try closing triage view
3. Expected: Notice disappears when view closes (no orphaned notices)
