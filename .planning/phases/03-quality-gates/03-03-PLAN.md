**Updated BookSchema (complete):**
```typescript
export const BookSchema = z.object({
  title: z.string().min(1, 'Title is required'),
  authors: z.array(z.string()).min(1, 'At least one author or editor is required'),
  year: z.string().min(1, 'Publication year is required').nullable(),
  publisher: z.string().min(1, 'Publisher is required').nullable(),
  // Optional fields that can be validated if present
  isbn: z.string().nullable().optional()
});
```

**What to change:**
1. REMOVE the TODO comment (lines 49-51)
2. ADD publisher field with validation: `publisher: z.string().min(1, 'Publisher is required').nullable(),`
3. ADD isbn field as optional: `isbn: z.string().nullable().optional()`

**Why nullable() AND min(1)?**
- `.nullable()`: Field can be NULL in database (not all books have publisher in Zotero)
- `.min(1)`: If field is present (not null), it must not be empty string
- Pattern matches JournalArticleSchema validation (doi, journal, year all use this pattern)

**Why isbn is optional:**
- Default config doesn't require ISBN (validation/types.ts line 50)
- Settings UI has toggle for ISBN, but defaults to off
- Many books (especially older ones) don't have ISBNs
- If user enables ISBN requirement via settings, they'd add it to requiredFields

**Error message consistency:**
- Use exact pattern from default config field labels
- "Publisher is required" matches settings UI label "Publisher"
