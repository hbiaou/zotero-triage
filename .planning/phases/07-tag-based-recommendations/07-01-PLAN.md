**Modify src/recommendations/recommendation-engine.ts:**

Replace the stub `calculateTagScore` method (currently returns 0) with full implementation following RESEARCH.md Pattern 3:

1. **Handle no tags:** If `!item.tags || item.tags.length === 0`, return 0 (no penalty, neutral)
2. **Normalize item tags:** Map `item.tags` to normalized strings using `normalizeTag()` from stemming.ts (import at top)
3. **Normalize profile tags:** Get entries from `profile.tags`, normalize each key using `normalizeTag()`
4. **Match and score:** For each normalized item tag, check if it matches any normalized profile tag (exact string equality after stemming)
5. **Sum weights:** Linear multi-match scoring - add weight of ALL matching profile tags (not just first match)
6. **Return raw score:** Return sum (not normalized; normalization happens in scoreItem caller)

**Multi-word tag handling (Claude's discretion per CONTEXT.md):**
Use exact match after stemming (don't split multi-word tags). 'machine learning' only matches 'machine learning', not 'machine' or 'learning' separately. Simpler and preserves semantic phrases.

**Items with no tags:**
Return 0 (neutral, no penalty). Tags are enhancement signal; absence doesn't indicate irrelevance.

**Imports needed:**
```typescript
import { normalizeTag } from '../utils/stemming';
```

**Example logic structure:**
```typescript
private calculateTagScore(item: ZoteroItem, profile: UserProfile): number {
  if (!item.tags || item.tags.length === 0) return 0;

  const itemTags = item.tags.map(t => normalizeTag(t)).filter(t => t.length > 0);
  if (itemTags.length === 0) return 0;

  // Build normalized profile tag map
  const normalizedProfile = new Map<string, number>();
  for (const [tag, weight] of profile.tags.entries()) {
    const normalized = normalizeTag(tag);
    if (normalized) {
      normalizedProfile.set(normalized, weight);
    }
  }

  // Linear multi-match: sum all matching weights
  let score = 0;
  for (const itemTag of itemTags) {
    const weight = normalizedProfile.get(itemTag);
    if (weight !== undefined) {
      score += weight;
    }
  }

  return score;
}
```
