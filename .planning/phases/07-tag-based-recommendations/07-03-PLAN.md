  <what-built>
Complete tag-based recommendation system:
- Profile tag extraction from seed papers (top 20, frequency-weighted)
- Tag scoring in recommendation engine (case-insensitive, stemmed matching)
- Adaptive learning from accept/reject feedback with weight decay
- User-configurable tag weight slider in settings (0.0-3.0)
  </what-built>
  <how-to-verify>
**Prerequisites:**
- Zotero library with tagged items (at least 20-30 items with tags)
- Obsidian with plugin reloaded after Plans 01-02 complete
- Plugin settings accessible

**Test Flow:**

**1. Profile Initialization:**
1. Open plugin settings → Reset profile (or start fresh)
2. Run onboarding wizard, select 5-15 seed papers that have tags
3. Complete wizard → profile should be created
4. Open Obsidian DevTools Console (Ctrl+Shift+I)
5. Inspect profile object in console or via plugin debug command
6. **Verify:** `profile.tags` Map exists with ~20 entries
7. **Verify:** Tag weights reflect frequency (tag in 3 papers = weight ~3.0)
8. **Verify:** Tags are lowercase and normalized

**2. Tag Scoring:**
1. Generate a new batch (5-10 items)
2. In DevTools console, inspect scored items or enable debug logging
3. **Verify:** Items with matching tags have non-zero `scoreBreakdown.tagScore`
4. **Verify:** Items without tags have `tagScore: 0`
5. **Verify:** Tag matches are case-insensitive ('Network' in item matches 'network' in profile)
6. **Verify:** Stemming works (if item has 'networks', matches profile 'network')

**3. Adaptive Learning:**
1. Accept an item with tags present in profile → wait for profile save (debounced)
2. Check profile in console → **Verify:** matching tag weights increased by ~0.2
3. Reject an item with tags present in profile → wait for profile save
4. Check profile in console → **Verify:** matching tag weights decreased by ~0.1
5. Accept/reject 10+ items → **Verify:** weight decay applied (weights drift toward 1.0)

**4. Settings Configuration:**
1. Open plugin settings
2. Locate "Tag weight" slider (should exist in advanced/recommendation section)
3. **Verify:** Default value is 1.5
4. Adjust slider to 0.0 → save → generate new batch
5. **Verify:** Tag scoring disabled (all items have `tagScore: 0` or tags don't affect ranking)
6. Adjust slider to 3.0 → save → generate new batch
7. **Verify:** Items with matching tags are heavily prioritized (top of batch)
8. Reload Obsidian → **Verify:** tag weight setting persists (still 3.0)

**5. Noise Tag Filtering:**
1. Add workflow tags to some Zotero items ('to-read', 'important', 'review')
2. Include these items in seed papers → regenerate profile
3. **Verify:** Workflow tags do NOT appear in profile.tags (filtered by isNoiseTag)

**6. Edge Cases:**
1. Select seed papers with NO tags → **Verify:** profile.tags is empty Map (no crash)
2. Score items with no tags → **Verify:** tagScore is 0, no errors
3. Items with empty string tags → **Verify:** handled gracefully (skipped during normalization)

**Expected Behavior:**
- Tag-based recommendations improve batch relevance
- Items with user's top tags rank higher
- Adaptive learning refines tag preferences over time
- User can tune tag importance via settings slider
- Noise tags filtered, no crashes on edge cases
  </how-to-verify>
