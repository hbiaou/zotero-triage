- SUPPORTED_SCHEMA_VERSIONS constant: { min: 100, max: 200 }

Create src/db/queries.ts with SQL query constants:

VERSION_QUERY: Select userdata schema version from version table.

ITEMS_QUERY: CTE-based query that:
- Joins items, itemTypes, itemData, fields, itemDataValues
- Excludes deletedItems, attachments, and notes
- Pivots EAV to columns: itemID, itemKey, dateAdded, dateModified, itemType
- Extracts fields: title, DOI, date, publicationTitle (journal), volume, pages, abstractNote
- Groups by itemID
- Orders by dateAdded DESC

CREATORS_QUERY: Parameterized query (?) for single item:
- Joins itemCreators, creators, creatorTypes
- Returns: firstName, lastName, fieldMode, creatorType, orderIndex
- Orders by orderIndex

ATTACHMENTS_QUERY: Parameterized query (?) for single item:
- Selects from itemAttachments
- Filters by parentItemID and contentType = 'application/pdf'
- Returns: itemID, linkMode, path, contentType

ITEM_TAGS_QUERY: Parameterized query (?) for single item:
- Joins itemTags and tags tables
- Returns tag names for an item

Export helper function formatCreator(row): handles fieldMode 0 (firstName + lastName) vs 1 (single field).
Export helper function parseYear(dateStr): extracts year from Zotero date string (various formats).

<task type="auto">
  <name>Task 2: Create ZoteroConnector class with sql.js</name>
  <files>src/db/zotero-connector.ts</files>
  <action>
Create src/db/zotero-connector.ts with ZoteroConnector class:

Properties:
- private db: Database | null
- private SQL: SqlJsStatic | null
- private pluginDir: string (for WASM location)
- private items: ZoteroItem[] (cached items)
- private isLoaded: boolean

Constructor:
- Takes pluginDir parameter
- Initializes db and SQL to null

Methods:

async initialize(): Promise<void>
- Load WASM binary from pluginDir using fs.readFileSync
- Call initSqlJs with wasmBinary option
- Store SQL instance

async connect(dbPath: string): Promise<void>
- If not initialized, call initialize()
- Read database file with fs.readFileSync
- Create new Database from Uint8Array buffer
- Call checkSchemaVersion and throw if unsupported

async checkSchemaVersion(): Promise<SchemaCheckResult>
- Execute VERSION_QUERY
- Parse version number
- Compare against SUPPORTED_SCHEMA_VERSIONS
- Return result with appropriate message

async loadItems(onProgress?: (loaded: number, total: number) => void): Promise<ZoteroItem[]>
- Execute ITEMS_QUERY to get raw items
- For each item (in chunks of 50 to avoid blocking):
  - Execute CREATORS_QUERY to get authors
  - Execute ATTACHMENTS_QUERY to get PDF path
  - Execute ITEM_TAGS_QUERY to get tags
  - Build ZoteroItem object
  - Call onProgress callback
  - Yield to event loop with setTimeout(0)
- Cache items in this.items
- Return items array

async getItem(itemID: number): Promise<ZoteroItem | null>
- Return from cache if available
- Otherwise query single item

close(): void
- Call db.close() if open
- Set db to null

async testConnection(dbPath: string): Promise<{ success: boolean, itemCount: number, schemaVersion: number }>
- Attempt connect
- Count items with simple query
- Return success status

Export ZoteroConnector class.

Important: Use fs from 'fs' and path from 'path' (Node.js built-ins) for file access since Zotero database is external to vault.
  </action>

File compiles without TypeScript errors.
Class exports correctly.
All methods are properly typed.
  </verify>
  <done>ZoteroConnector class ready with sql.js integration, chunked loading, and schema detection</done>
