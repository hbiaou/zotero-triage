Create src/registry/registry-service.ts with RegistryService class:

Properties:
- private registry: Registry
- private plugin: Plugin (for saveData/loadData)
- private debouncedSave: DebouncedFunc (from lodash.debounce)

Constructor:
- Takes plugin parameter
- Initialize registry to default (empty entries)
- Create debouncedSave with 2000ms delay that:
  - Updates registry.lastModified
  - Calls plugin.saveData({ registry: this.registry })

Methods:

async load(): Promise<void>
- Call plugin.loadData()
- Extract registry from data (or use default)
- Validate registry structure:
  - If entries is not an object, reset to default
  - Log warning if invalid data found
- Update version if migration needed (future-proofing)

getState(itemId: string | number): RegistryEntry['state']
- Convert itemId to string
- Return entry state or 'unseen' if not found

markState(itemId: string | number, state: RegistryEntry['state']): void
- Convert itemId to string
- Create/update entry with state and current timestamp
- Call debouncedSave()

isImported(itemId: string | number): boolean
- Return getState(itemId) === 'imported'

getStats(): RegistryStats
- Count entries by state
- Return stats object

getEntriesByState(state: RegistryEntry['state']): string[]
- Return array of itemIds with given state

flush(): Promise<void>
- Cancel any pending debounced save
- Perform immediate save
- Useful for plugin unload

private getDefault(): Registry
- Return { version: 1, entries: {}, lastModified: Date.now() }

Export RegistryService class.

Import debounce from 'lodash.debounce'.
