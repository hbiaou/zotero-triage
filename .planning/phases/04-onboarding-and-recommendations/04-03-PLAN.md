Create ProfileInitializer class for extracting signals from seed papers and creating initial profile:

**Constructor:**
```typescript
constructor(
  connector: ZoteroConnector,
  profileService: ProfileService,
  keywordExtractor: typeof extractKeywords
)
```

**Main method:**
```typescript
async initializeProfile(
  seedPaperIds: string[],
  preferences: { relevanceVsDiversity: number, recencyBoost: boolean }
): Promise<UserProfile>
```

**Initialization algorithm (per RESEARCH.md and CONTEXT.md):**

1. **Fetch seed papers:**
   - Get items from connector using seedPaperIds
   - Handle missing items gracefully (log warning, continue with available)

2. **Extract signals with frequency counting:**
   - For each seed paper:
     - Tags: Extract from item.tags
     - Authors: Extract from item.authors
     - Keywords: Extract using keywordExtractor(title + abstract)
   - Count frequency of each signal across all seeds
   - Frequency becomes initial weight (appears in 5 papers = weight 5.0)

3. **Create profile:**
   - Build tags Map<string, number> with frequency weights
   - Build authors Map<string, number> with frequency weights
   - Build keywords Map<string, number> with frequency weights
   - Store seedPaperIds for reference
   - Store preferences (relevanceVsDiversity, recencyBoost)
   - Set timestamps (createdAt, updatedAt = Date.now())

4. **Persist profile:**
   - Call profileService.createProfile(...)
   - Trigger save

**Frequency-based weighting rationale (per RESEARCH.md):**
- Signal appears in 1 seed paper → weight 1.0
- Signal appears in 5 seed papers → weight 5.0
- Signal appears in all 10 seeds → weight 10.0
- Higher frequency = stronger signal of user interest

**Example:**
```
Seeds: 10 papers
Tag "machine-learning" appears in 8 papers → weight 8.0
Tag "computer-vision" appears in 2 papers → weight 2.0
Author "LeCun, Yann" appears in 3 papers → weight 3.0
Keyword "neural" appears in 9 papers → weight 9.0
```

Pattern: Service class with dependencies, async initialization method, frequency-based aggregation logic.

Use CONTEXT.md: "Frequency-based weighting (signals appearing in more seed papers get higher weight)".
