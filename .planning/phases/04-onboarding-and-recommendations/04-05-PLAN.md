**Add wizard method:**
```typescript
private showSetupWizard(): void {
  const wizard = new SetupWizardModal(
    this.app,
    this,
    async (wizardData) => {
      // Initialize profile from wizard data
      await this.profileInitializer.initializeProfile(
        wizardData.seedPaperIds,
        {
          relevanceVsDiversity: wizardData.relevanceVsDiversity,
          recencyBoost: wizardData.recencyBoost
        }
      );
      new Notice('Setup complete! Your profile is ready.');
    },
    () => {
      // User skipped wizard
      new Notice('Setup skipped. Configure manually via settings.');
    }
  );
  wizard.open();
}
```

**Defer actions:**
No learning needed for defer (neutral action, doesn't indicate interest).

**Why this placement:**
- Learning happens AFTER registry updates (ensures state consistency)
- Learning happens BEFORE undo window (profile updates immediately)
- If user undoes, action is already learned (acceptable tradeoff - undo is rare)
