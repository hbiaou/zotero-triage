**Add dependencies to constructor:**
```typescript

  registry: RegistryService,
  profileService: ProfileService,
  recommendationEngine: RecommendationEngine,
  adaptiveLearner: AdaptiveLearner
)
```

**Update generateBatch method:**

Current logic (from 02-01):
1. Get all cached items
2. Filter by registry state (exclude imported, rejected)
3. Sort by dateAdded descending (most recent first)
4. Take first N items

**New logic with profile awareness:**
1. Get all cached items
2. Filter by registry state (exclude imported, rejected)
3. **Check if profile exists:**
   - **If profile exists:** Score items using recommendationEngine.scoreItems(), sort by score descending
   - **If no profile:** Fall back to original logic (sort by dateAdded descending)
4. Take first N items
5. Mark as 'proposed' in registry

**Add learning methods:**
```typescript
recordAccept(item: ZoteroItem): void {
  if (profileService.hasProfile()) {
    adaptiveLearner.learnFromAccept(item);
  }
}

recordReject(item: ZoteroItem): void {
  if (profileService.hasProfile()) {
    adaptiveLearner.learnFromReject(item);
  }
}
```

**Wire learning into triage actions:**
These methods will be called from triage-view.ts when user accepts/rejects items.

**Backward compatibility:**
- Plugin works without profile (uses date-based sorting)
- Profile-aware scoring only activates when profile exists
- Learning only happens when profile exists

**Config handling:**
Read relevanceVsDiversity and recencyBoost from profile when scoring:
```typescript

if (profile) {
  const config = {
    relevanceVsDiversity: profile.relevanceVsDiversity,
    recencyBoost: profile.recencyBoost
  };

}
```

```typescript
containerEl.createEl('h2', { text: 'Research Profile' });

const profileStatus = new Setting(containerEl)
  .setName('Profile Status')
  .setDesc(profileService.hasProfile()
    ? `Profile configured with ${seedCount} seed papers`
    : 'No profile configured — using date-based batch generation');

if (!profileService.hasProfile()) {
  profileStatus.addButton(button => button
    .setButtonText('Run Setup Wizard')
    .setCta()
    .onClick(() => {
      // Open SetupWizardModal
      const wizard = new SetupWizardModal(
        this.app,
        this.plugin,
        async (profile) => {
          await profileInitializer.initializeProfile(profile.seedPaperIds, profile.preferences);
          new Notice('Profile created successfully');
          this.display(); // Refresh settings
        },
        () => {
          new Notice('Setup skipped — configure manually via settings');
        }
      );
      wizard.open();
    }));
} else {
  profileStatus.addButton(button => button
    .setButtonText('Re-run Wizard')
    .onClick(() => {
      // Same as above, but clears existing profile first
    }));

  profileStatus.addButton(button => button
    .setButtonText('Clear Profile')
    .setWarning()
    .onClick(async () => {
      if (confirm('This will delete your profile and reset to date-based batch generation. Continue?')) {
        profileService.clearProfile();
        await this.plugin.saveSettings();
        new Notice('Profile cleared');
        this.display();
      }
    }));
}

// Embed ProfileEditor component if profile exists
if (profileService.hasProfile()) {
  const editorContainer = containerEl.createDiv({ cls: 'profile-editor-container' });
  const editor = new ProfileEditor(
    editorContainer,
    this.plugin.profileService,
    () => {
      // onProfileChange callback
      this.plugin.saveSettings();
    }
  );
}
```
