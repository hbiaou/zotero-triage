Create src/services/resilience.ts starting with CircuitBreaker:

1. **CircuitBreakerConfig interface**:
   - failureThreshold: number (default: 5) - consecutive failures to open circuit
   - successThreshold: number (default: 2) - successes to close from half-open
   - timeout: number (default: 60000ms) - time before trying half-open

2. **CircuitBreakerState type**: 'closed' | 'open' | 'half-open'

3. **CircuitBreaker class**:

   **Properties**:
   - private state: CircuitBreakerState = 'closed'
   - private failureCount: number = 0
   - private successCount: number = 0
   - private lastFailureTime: number = 0
   - private readonly config: CircuitBreakerConfig

   **Constructor**: Takes Partial<CircuitBreakerConfig>, applies defaults

   **Methods**:
   - `isOpen(): boolean`
     Returns true if circuit is open (blocking requests)
     Also checks if timeout expired and transitions to half-open

   - `isHalfOpen(): boolean`
     Returns true if in half-open state (allowing probe request)

   - `recordSuccess(): void`
     Resets failure count
     If half-open: increment successCount, close if threshold met

   - `recordFailure(): void`
     Increment failureCount, update lastFailureTime
     Open circuit if threshold met

   - `getState(): CircuitBreakerState`
     Returns current state

   - `reset(): void`
     Force reset to closed state (for testing/manual recovery)

4. **State machine logic**:
   ```
   closed -> open: failureCount >= failureThreshold
   open -> half-open: current time > lastFailureTime + timeout
   half-open -> closed: successCount >= successThreshold
   half-open -> open: any failure
   ```

Add ResilienceService to src/services/resilience.ts:

1. **RetryConfig interface**:
   - maxRetries: number (default: 3)
   - baseDelayMs: number (default: 1000)
   - maxDelayMs: number (default: 30000)
   - backoffMultiplier: number (default: 2)
   - jitterFraction: number (default: 0.5) - ±50% randomization

2. **ResilienceService class**:

   **Properties**:
   - private circuits: Map<string, CircuitBreaker>
   - private readonly retryConfig: RetryConfig
   - private readonly circuitConfig: CircuitBreakerConfig

   **Constructor**: Takes Partial<RetryConfig>, Partial<CircuitBreakerConfig>

   **Methods**:

   - `async execute<T>(
       key: string,
       operation: () => Promise<T>,
       options?: { isRetryable?: (error: any) => boolean }
     ): Promise<T>`
     Main entry point:
     1. Get or create circuit for key
     2. Check if circuit is open (throw if so)
     3. Try operation with retry logic
     4. Record success/failure on circuit
     5. Return result or throw

   - `private async executeWithRetry<T>(
       operation: () => Promise<T>,
       isRetryable: (error: any) => boolean
     ): Promise<T>`
     1. Loop up to maxRetries
     2. Try operation
     3. On error: check if retryable
     4. Extract retry-after header if available
     5. Calculate backoff delay (use retry-after if present, else exponential)
     6. Sleep and continue

   - `private calculateBackoff(attempt: number): number`
     ```typescript
     const exponential = this.retryConfig.baseDelayMs *
       Math.pow(this.retryConfig.backoffMultiplier, attempt);
     const capped = Math.min(exponential, this.retryConfig.maxDelayMs);
     const jitter = capped * (1 - this.retryConfig.jitterFraction/2 +
       Math.random() * this.retryConfig.jitterFraction);
     return Math.round(jitter);
     ```

   - `private extractRetryAfter(error: any): number | null`
     Look for retry-after in error.headers or error.response.headers
     Parse as integer (seconds), return null if not found

   - `private getOrCreateCircuit(key: string): CircuitBreaker`
     Lazy-create circuit per key

   - `getCircuitState(key: string): CircuitBreakerState | null`
     Return state for debugging/monitoring

   - `resetCircuit(key: string): void`
     Force reset circuit to closed

3. **Default isRetryable function**:
   - 429: Retryable (rate limit)
   - 500-599: Retryable (server error, except 529)
   - Network errors: Retryable
   - 401, 403: Not retryable (auth errors)
   - 400, 404: Not retryable (client errors)

4. **Helper**:
   - `private sleep(ms: number): Promise<void>`
     Return new Promise(resolve => setTimeout(resolve, ms))
