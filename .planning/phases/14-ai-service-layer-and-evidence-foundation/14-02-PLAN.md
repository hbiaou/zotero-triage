  <action>
Create src/ai/base-provider.ts with abstract base class:

1. **BaseAIProvider abstract class** implementing AIProvider interface:

   **Properties**:
   - readonly providerId: ProviderID
   - readonly models: AIModel[] (from models.ts catalog)
   - protected apiKey: string | null = null
   - protected baseUrl: string (provider-specific endpoint)

   **Constructor**:
   - Takes providerId parameter
   - Loads models from SUPPORTED_MODELS[providerId]

   **Abstract methods** (must be implemented by subclasses):
   - protected abstract buildRequestBody(request: AIRequest): unknown
   - protected abstract parseResponse(response: unknown): AIResponse
   - protected abstract getHeaders(): Record<string, string>

   **Concrete methods**:
   - `async initialize(apiKey: string): Promise<void>`
     Sets apiKey, calls validateCredentials(), throws if invalid

   - `async complete(request: AIRequest): Promise<AIResponse>`
     1. Check apiKey is set (throw AIServiceError if not)
     2. Build request body using abstract method
     3. Make fetch call to baseUrl with headers
     4. Handle HTTP errors (throw AIServiceError with isRetryable flag)
     5. Parse response using abstract method
     6. Return AIResponse

   - `async validateCredentials(): Promise<boolean>`
     Make lightweight API call to verify key works
     Return true if successful, false otherwise

   **Error handling in complete()**:
   - 401/403: Not retryable (invalid key)
   - 429: Retryable, extract retry-after header
   - 500-599: Retryable (server error)
   - Network errors: Retryable
   - Parse errors: Not retryable

2. **Import types from './types'**
3. **Import SUPPORTED_MODELS from './models'**

1. **Provider registry** (internal):
   Map<ProviderID, () => BaseAIProvider>
   Initially empty - providers register themselves on import

2. **registerProvider function**:
   ```typescript
   export function registerProvider(
     providerId: ProviderID,
     factory: () => BaseAIProvider
   ): void
   ```
   Adds provider constructor to registry

3. **createProvider function**:
   ```typescript
   export async function createProvider(
     providerId: ProviderID,
     apiKey: string
   ): Promise<BaseAIProvider>
   ```
   - Look up factory in registry
   - Throw if provider not registered
   - Create instance using factory
   - Call initialize(apiKey)
   - Return initialized provider

4. **ProviderFactory class** (alternative OOP interface):
   - constructor(secretStorage: SecretStorageService)
   - async getProvider(providerId: ProviderID): Promise<BaseAIProvider | null>
     Retrieves API key from secret storage, creates provider
   - async getConfiguredProviders(): Promise<ProviderID[]>
     Returns list of providers with stored keys
   - isProviderRegistered(providerId: ProviderID): boolean
     Checks if provider implementation exists

5. **Import types**:
   - ProviderID, AIProvider from './types'
   - BaseAIProvider from './base-provider'
   - SecretStorageService from '../services/secret-storage'

Note: Concrete providers (OpenAI, Google, etc.) will register themselves when imported in Plan 03.
