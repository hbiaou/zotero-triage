  <name>Task 1: Create AIService orchestrator</name>
  <files>src/services/ai-service.ts</files>
  <action>
Create src/services/ai-service.ts with unified orchestrator:

1. **AIServiceConfig interface**:
   - selectedProvider: ProviderID | null
   - selectedModel: string | null
   - fallbackOrder: ProviderID[]

2. **AIService class**:

   **Properties**:
   - private app: App
   - private secretStorage: SecretStorageService
   - private providerFactory: ProviderFactory
   - private resilience: ResilienceService
   - private config: AIServiceConfig
   - private currentProvider: BaseAIProvider | null = null

   **Constructor**:
   - Takes App, SecretStorageService
   - Creates ProviderFactory with secretStorage
   - Creates ResilienceService with default config

   **Methods**:

   - `async initialize(config: AIServiceConfig): Promise<void>`
     Store config
     If selectedProvider set, try to load provider

   - `async complete(request: AIRequest): Promise<AIResponse>`
     1. Ensure provider is loaded
     2. Wrap call with resilience.execute()
     3. Use provider's complete() method
     4. Handle fallback on failure if configured
     5. Return response or throw

   - `async loadProvider(providerId: ProviderID): Promise<boolean>`
     1. Get API key from secretStorage
     2. Create provider using factory
     3. Store as currentProvider
     4. Return success/failure

   - `async testProvider(providerId: ProviderID, apiKey: string): Promise<boolean>`
     1. Create temporary provider
     2. Initialize with key
     3. Call validateCredentials()
     4. Return result (don't store)

   - `getConfiguredProviders(): Promise<ProviderID[]>`
     Delegate to secretStorage.listConfiguredProviders()

   - `getCurrentProvider(): ProviderID | null`
     Return config.selectedProvider

   - `getCurrentModel(): string | null`
     Return config.selectedModel

   - `isReady(): boolean`
     Return currentProvider !== null

3. **Fallback logic in complete()**:
   If primary fails and fallbackOrder configured:
   - Try next provider in order
   - Skip if no API key configured
   - Return first successful response
   - Throw original error if all fail

Import all dependencies from ai/ and services/.

   // Initialize evidence extractor (needs Zotero data path)
   const zoteroDataPath = this.getZoteroDataPath();
   if (zoteroDataPath) {
     this.evidenceExtractor = new EvidenceExtractor(

     return path.dirname(this.settings.zoteroDbPath);
