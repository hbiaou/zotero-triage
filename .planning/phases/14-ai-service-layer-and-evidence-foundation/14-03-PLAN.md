**OpenAI Provider (src/ai/providers/openai-provider.ts)**:

1. **OpenAIProvider class** extending BaseAIProvider:
   - providerId: 'openai'
   - baseUrl: 'https://api.openai.com/v1/chat/completions'

2. **buildRequestBody(request: AIRequest)**: OpenAI Chat Completions format
   ```json
   {
     "model": request.model,
     "messages": [
       {"role": "system", "content": request.systemPrompt || "You are a helpful assistant."},
       {"role": "user", "content": request.prompt}
     ],
     "temperature": request.temperature || 0.7,
     "max_tokens": request.maxTokens || 4096
   }
   ```

3. **getHeaders()**:
   ```
   Authorization: Bearer {apiKey}
   Content-Type: application/json
   ```

4. **parseResponse(response)**: Extract from OpenAI response
   - content: response.choices[0].message.content
   - tokensUsed: { input: response.usage.prompt_tokens, output: response.usage.completion_tokens }
   - finishReason: map response.choices[0].finish_reason

5. **validateCredentials()**: Call /v1/models endpoint to verify key

6. **Auto-register**: At module level, call registerProvider('openai', () => new OpenAIProvider())

**Google Provider (src/ai/providers/google-provider.ts)**:

1. **GoogleProvider class** extending BaseAIProvider:
   - providerId: 'google'
   - baseUrl: 'https://generativelanguage.googleapis.com/v1beta/models'

2. **buildRequestBody(request: AIRequest)**: Google Generative AI format
   ```json
   {
     "contents": [
       {"role": "user", "parts": [{"text": request.prompt}]}
     ],
     "systemInstruction": {"parts": [{"text": request.systemPrompt}]},
     "generationConfig": {
       "temperature": request.temperature || 0.7,
       "maxOutputTokens": request.maxTokens || 4096
     }
   }
   ```

3. **getHeaders()**:
   ```
   Content-Type: application/json
   x-goog-api-key: {apiKey}
   ```

4. **complete() override**: URL includes model name
   `${baseUrl}/${request.model}:generateContent`

5. **parseResponse(response)**: Extract from Google response
   - content: response.candidates[0].content.parts[0].text
   - tokensUsed: { input: response.usageMetadata.promptTokenCount, output: response.usageMetadata.candidatesTokenCount }
   - finishReason: map response.candidates[0].finishReason

6. **validateCredentials()**: Call /models endpoint with key

7. **Auto-register**: registerProvider('google', () => new GoogleProvider())

**Anthropic Provider (src/ai/providers/anthropic-provider.ts)**:

1. **AnthropicProvider class** extending BaseAIProvider:
   - providerId: 'anthropic'
   - baseUrl: 'https://api.anthropic.com/v1/messages'

2. **buildRequestBody(request: AIRequest)**: Anthropic Messages format
   ```json
   {
     "model": request.model,
     "max_tokens": request.maxTokens || 4096,
     "system": request.systemPrompt || "You are a helpful assistant.",
     "messages": [
       {"role": "user", "content": request.prompt}
     ]
   }
   ```

3. **getHeaders()**:
   ```
   x-api-key: {apiKey}
   anthropic-version: 2023-06-01
   Content-Type: application/json
   ```

4. **parseResponse(response)**: Extract from Anthropic response
   - content: response.content[0].text
   - tokensUsed: { input: response.usage.input_tokens, output: response.usage.output_tokens }
   - finishReason: map response.stop_reason ('end_turn' -> 'stop', 'max_tokens' -> 'max_tokens')

5. **Error handling note**: Anthropic returns 529 for server overload (not retryable by client, different from 429)

6. **validateCredentials()**: Make minimal request to verify key

7. **Auto-register**: registerProvider('anthropic', () => new AnthropicProvider())

**OpenRouter Provider (src/ai/providers/openrouter-provider.ts)**:

   - baseUrl: 'https://openrouter.ai/api/v1/chat/completions'

2. **buildRequestBody(request: AIRequest)**: OpenAI-compatible format (OpenRouter uses OpenAI format)
   ```json
   {
     "model": request.model,
     "messages": [
       {"role": "system", "content": request.systemPrompt || "You are a helpful assistant."},
       {"role": "user", "content": request.prompt}
     ],
     "temperature": request.temperature || 0.7,
     "max_tokens": request.maxTokens || 4096
   }
   ```

3. **getHeaders()**:

   ```
   Content-Type: application/json
   HTTP-Referer: https://github.com/zotero-triage

   ```
   Note: HTTP-Referer and X-Title are required by OpenRouter for tracking

4. **parseResponse(response)**: Same as OpenAI format
   - content: response.choices[0].message.content
   - tokensUsed: { input: response.usage.prompt_tokens, output: response.usage.completion_tokens }

5. **validateCredentials()**: Call /api/v1/models to verify key

6. **Auto-register**: registerProvider('openrouter', () => new OpenRouterProvider())
