   - maxTokens?: number (default 4096)

4. **AIResponse interface**:
   - content: string
   - tokensUsed: { input: number; output: number }
   - provider: ProviderID
   - model: string
   - finishReason: 'stop' | 'max_tokens' | 'error'
   - rawResponse?: unknown

   - readonly providerId: ProviderID
   - readonly models: AIModel[]
   - complete(request: AIRequest): Promise<AIResponse>

   - providerId: ProviderID
   - apiKey: string (runtime only, not persisted)

8. **EvidenceExtraction interface**:
   - level: EvidenceLevel
   - content: string

   - tokenEstimate?: number

9. **AIServiceError class** extending Error:
   - providerId: ProviderID

<task type="auto">
  <name>Task 2: Create SecretStorage service for encrypted API keys</name>
  <files>src/services/secret-storage.ts</files>
  <action>
Create src/services/secret-storage.ts implementing secure API key storage:

1. **SecretStorageService class**:
   - Constructor takes Obsidian App instance
   - Uses Obsidian's built-in secret storage (app.loadSecret/app.saveSecret)

2. **Methods**:
   - `async setAPIKey(providerId: ProviderID, key: string): Promise<void>`
     - Stores key with prefix 'zotero-triage-ai-key-{providerId}'
     - Uses app.saveSecret() for encrypted storage

   - `async getAPIKey(providerId: ProviderID): Promise<string | null>`
     - Retrieves key using app.loadSecret()
     - Returns null if not found

   - `async deleteAPIKey(providerId: ProviderID): Promise<void>`
     - Removes key using app.saveSecret(key, '')

   - `async hasAPIKey(providerId: ProviderID): Promise<boolean>`
     - Returns true if key exists and is non-empty

   - `async listConfiguredProviders(): Promise<ProviderID[]>`
     - Returns array of provider IDs that have keys configured
     - Checks all 4 providers: openai, google, anthropic, openrouter

3. **Key naming convention**: 'zotero-triage-ai-key-{providerId}'
   Example: 'zotero-triage-ai-key-openai', 'zotero-triage-ai-key-google'

4. **Error handling**:
   - Wrap all operations in try/catch
   - Log errors but don't throw (graceful degradation)
   - Return null/false on failure rather than crashing

5. **Import ProviderID from '../ai/types'**

Reference Obsidian API:
- app.loadSecret(key: string): Promise<string>
- app.saveSecret(key: string, value: string): Promise<void>

Note: These methods automatically use OS keychain (macOS Keychain, Windows Credential Manager, Linux Secret Service) when available, falling back to encrypted file storage.
