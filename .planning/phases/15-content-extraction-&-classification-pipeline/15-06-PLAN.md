Enhance to:
1. Add domainClassifier import at top of file
2. Call domainClassifier.classify(item) to get ClassificationResult

4. If low confidence: trigger ClassificationModal to let user override
5. Store classification result (domain + confidence) in enrichment metadata
6. Set knowledge_domain field from classification result

New code structure:
```
async recordAccept(item: ZoteroItem, selectedDomain?: Domain): Promise<void> {
  // Existing learning logic
  if (this.profileService.hasProfile()) {
    this.adaptiveLearner.learnFromAccept(item);
  }

  // NEW: Classify item
  const classificationResult = await this.domainClassifier.classify(item);

  // NEW: Show modal if confidence is low
  if (classificationResult.confidence < CONFIDENCE_THRESHOLD) {
    // Trigger ClassificationModal
    // User will select domain or accept suggestion
    // selectedDomain parameter comes from modal result
  }

  // NEW: Store classification in enrichment metadata
  const domainToUse = selectedDomain || classificationResult.domain;
  this.registry.setEnrichmentMetadata(item.key, {
    knowledge_domain: domainToUse,
    classification_confidence: classificationResult.confidence,
    template_used: domainToUse
  });
}
```

Notes:
- CONFIDENCE_THRESHOLD = 0.70 (from Phase 15 decisions)
- Modal trigger is asynchronous - user must confirm before enrichment proceeds
- Selected domain persists in registry for later retrieval
- signature change: async method, optional selectedDomain parameter
