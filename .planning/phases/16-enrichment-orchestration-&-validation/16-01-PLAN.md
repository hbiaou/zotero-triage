Create src/services/enrichment-service.ts with EnrichmentService class:

**Class structure:**
- Constructor takes: AIService, EvidenceExtractor, DomainClassifier, App (for vault access)
- Main method: `async enrich(item: ZoteroItem, classification: ClassificationResult): Promise<EnrichmentResult>`

**Enrichment workflow:**
1. Extract evidence using EvidenceExtractor (already has extract() method from Phase 14-05)
2. Get domain template using getDomainTemplate(classification.domain) from templates.ts
3. Build LLM prompt with:
   - System instruction: "You are a literature note enrichment assistant. Fill template sections using ONLY the provided evidence. Use 'N/A - insufficient evidence' for sections without supporting text. Preserve verbatim quotes for key claims and methods."
   - Evidence context: Include fulltext/notes/abstract from EvidenceExtraction
   - Template structure: Show template sections to fill
   - Item metadata: title, authors, year, itemType
   - Output format: "Return valid Markdown with YAML frontmatter. No code blocks. No emojis."
4. Call AIService.generateCompletion() with prompt (use 2-minute timeout)
5. Parse LLM response and validate basic structure (has frontmatter, has body)
6. Return EnrichmentResult with: content (full markdown), metadata (parsed YAML), evidenceUsed (what sources were referenced)

**Template population rules (from CONTEXT.md):**
- Missing evidence sections: Show "N/A - insufficient evidence" placeholder
- Content style: Mixed (verbatim quotes for claims/methods, paraphrasing for context)
- Conflicting evidence: PDF takes priority over notes
- Template flexibility: Hybrid (core sections mandatory, allow 1-2 extra sections for unique content)

**Error handling:**
- LLM timeout (>2 min): Throw EnrichmentTimeoutError
- LLM API failure: Throw EnrichmentAPIError
- Invalid response structure: Throw EnrichmentParseError
- All errors include item.itemID for tracking

```typescript
export interface EnrichmentResult {
  content: string;              // Full markdown with frontmatter + body

    level: EvidenceLevel;
    sources: string[];          // Which evidence sources contributed
  };
  enrichedAt: string;           // ISO timestamp
  modelUsed: string;            // AI model identifier
  tokenCount?: number;          // Estimated tokens consumed
}

export class EnrichmentTimeoutError extends Error {
  constructor(public itemId: number, message: string) {
    super(message);
    this.name = 'EnrichmentTimeoutError';
  }
}

export class EnrichmentAPIError extends Error {
  constructor(public itemId: number, message: string, public cause?: Error) {
    super(message);
    this.name = 'EnrichmentAPIError';
  }
}

export class EnrichmentParseError extends Error {
  constructor(public itemId: number, message: string) {
    super(message);
    this.name = 'EnrichmentParseError';
  }
}
```

```typescript
const prompt = `You are enriching a literature note for: "${item.title}"

EVIDENCE AVAILABLE:
${evidence.level === 'FullText' ? 'Full PDF text' : evidence.level === 'Notes' ? 'Zotero notes and annotations' : 'Abstract only'}

${evidence.fullText ? `FULL TEXT:\n${evidence.fullText.substring(0, 30000)}\n` : ''}
${evidence.notes ? `NOTES:\n${evidence.notes}\n` : ''}
${evidence.abstract ? `ABSTRACT:\n${evidence.abstract}\n` : ''}

TEMPLATE TO FILL (${classification.domain} domain):
${templateStructure}

METADATA:
Title: ${item.title}
Authors: ${item.creators?.map(c => c.name || `${c.firstName} ${c.lastName}`).join(', ')}
Year: ${item.year}
Type: ${item.itemType}

INSTRUCTIONS:
1. Fill each template section using ONLY the evidence above
2. Use "N/A - insufficient evidence" for sections without supporting text
3. Preserve verbatim quotes for key claims, methods, and results
4. Use mixed style: quotes for claims, paraphrasing for context
5. Generate 6-8 relevant tags at the end (single line)
6. Output format: YAML frontmatter (---\nfields\n---) followed by markdown body
7. NO code blocks wrapping the output
8. NO emojis in the content

Generate the enriched literature note now.`;
```
