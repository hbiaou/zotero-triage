    **Create filterItems() method:**
    ```typescript
    private filterItems(items: ZoteroItem[]): ZoteroItem[] {
      if (this.searchQuery.length === 0) {
        return items; // No filter, return all
      }

      return items.filter(item => {
        const query = this.searchQuery;

        // Match against title
        if (item.title.toLowerCase().includes(query)) {
          return true;
        }

        // Match against authors
        if (item.authors.some(a => a.toLowerCase().includes(query))) {
          return true;
        }

        // Match against tags (if exist)
        if (item.tags?.some(t => t.toLowerCase().includes(query))) {
          return true;
        }

        return false;
      });
    }
    ```

    **Modify renderBatch() to apply filter:**
    - After stats panel and progress bar, call `this.renderSearchFilter(container)`
    - When rendering cards, use `this.filterItems(this.currentBatch.items)` instead of `this.currentBatch.items` directly
    - Pattern: `const displayedItems = this.filterItems(this.currentBatch.items);`
    - Loop over `displayedItems` to create cards

    **Preserve search query across state changes:**

    - `refresh()` calls `renderBatch()` which re-applies `filterItems()`
    - Search query persists in `this.searchQuery` field
    - Input value preserved via DOM (not cleared on re-render)
