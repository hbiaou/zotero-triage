    **In seed-paper-picker.ts:**
    Add scroll position tracking:
    ```typescript
    private scrollPosition: number = 0;
    ```

    **Modify toggleSelection() to preserve scroll:**
    ```typescript
    private toggleSelection(itemId: string): void {
      // Save scroll position before re-render
      const listContainer = this.container.querySelector('.seed-picker-list') as HTMLElement;
      if (listContainer) {
        this.scrollPosition = listContainer.scrollTop;
      }

      // Existing toggle logic
      if (this.selectedIds.has(itemId)) {
        this.selectedIds.delete(itemId);
      } else {
        if (this.selectedIds.size >= this.MAX_SELECTION) {
          return;
        }
        this.selectedIds.add(itemId);
      }

      this.onSelectionChange(Array.from(this.selectedIds));

      // Re-render to update UI
      this.render();

      // Restore scroll position after re-render
      requestAnimationFrame(() => {
        const newListContainer = this.container.querySelector('.seed-picker-list') as HTMLElement;
        if (newListContainer) {
          newListContainer.scrollTop = this.scrollPosition;
        }
      });
    }
    ```

    **Why requestAnimationFrame:** Ensures DOM re-render completes before restoring scroll. Prevents race condition where scrollTop is set before new DOM is ready.

    **Why max-width: 90vw:** Leaves 5vw margin on each side for breathing room. Works on screens as narrow as 800px. Prevents horizontal scrollbar that appears when content exceeds viewport.

    **Avoid:** Don't use fixed pixel widths (breaks on different screen sizes). Don't set overflow: hidden on modal (prevents scrolling when needed). Don't restore scroll in render() (too early, DOM not ready).
  </action>

    **In triage-view.ts:**
    Add scroll position state and helper methods:
    ```typescript
    private scrollPosition: number = 0;

    private saveScrollPosition(): void {
      const cardContainer = this.containerEl.querySelector('.zotero-triage-card-list') as HTMLElement;
      if (cardContainer) {
        this.scrollPosition = cardContainer.scrollTop;
      }
    }

    private restoreScrollPosition(): void {
      requestAnimationFrame(() => {
        const cardContainer = this.containerEl.querySelector('.zotero-triage-card-list') as HTMLElement;
        if (cardContainer) {
          cardContainer.scrollTop = this.scrollPosition;
        }
      });
    }
    ```

    **Modify performAccept() to preserve scroll:**
    Add at start: `this.saveScrollPosition();`
    Add before final `this.refresh()`: `this.restoreScrollPosition();`

    **Modify handleReject() to preserve scroll:**
    Add at start: `this.saveScrollPosition();`
    Add before final `this.refresh()`: `this.restoreScrollPosition();`

    **Modify handleDefer() to preserve scroll:**
    Add at start: `this.saveScrollPosition();`
    Add before final `this.refresh()`: `this.restoreScrollPosition();`

    **Pattern for all three methods:**
    ```typescript
    private handleX(item: ZoteroItem): void {
      this.saveScrollPosition();

      // Existing logic...

      this.restoreScrollPosition();
      this.refresh();
    }
    ```

    **Why all three handlers:** User can be scrolled down reviewing cards when they accept/reject/defer. Each action triggers refresh(), which would reset scroll to top without preservation.

    **Why requestAnimationFrame:** Same reason as seed picker - ensures DOM update completes before setting scrollTop.

    **Avoid:** Don't save scroll in refresh() (called from many places, would overwrite position). Don't use setTimeout (unreliable, requestAnimationFrame is proper timing for DOM updates).
