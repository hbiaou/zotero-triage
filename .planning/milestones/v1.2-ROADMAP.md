# Milestone v1.2: Library Scope Filtering & Preflight Checks

**Status:** ✅ SHIPPED 2026-01-29
**Phases:** 9-13
**Total Plans:** 8

## Overview

Ensure only relevant, high-quality items from user's personal library enter the recommendation pipeline by filtering unwanted sources and detecting issues before onboarding.

This milestone focused on data quality and user awareness by implementing query-level library filtering to exclude group libraries, feeds, trash, and retracted items, creating a comprehensive preflight check system to warn users about library health issues, and establishing settings persistence for recommendation preferences.

## Milestone Summary

**Key Decisions:**

- SQL-level filtering via INNER JOIN (query-time vs post-processing for performance)
- DOI-first duplicate matching hierarchy (conservative, low false positives)
- Sequential preflight checks (UI simplicity vs parallel execution)
- Color-coded severity levels (red/yellow/blue PatternFly standards)
- Settings-first architecture (preferences persist independently from profile lifecycle)
- Encapsulated query methods (type-safe queryLibraryStats() vs generic query())

**Issues Resolved:**

- Library filtering verified with 12,876-item production database (9,392 items after exclusions)
- Standalone notes correctly included as research artifacts (exclude only child notes)
- Zotero 6/7 compatibility via table existence checks (deletedItems, retractedItems)
- Mid-milestone audit gap closed with Phase 13 (connector.query() missing)
- Settings persistence complete (relevance vs diversity now persists from wizard)

**Tech Debt Incurred:**

None - all features production-ready
