## 4. End-to-End User Flows

All 6 primary user flows verified complete:

### Flow 1: First-Time Setup (Onboarding) ✓
```
Plugin load detection → Setup wizard opens → Database config →
Preferences selection → Seed paper picker (5-15 papers) →
Profile initialization → Success notice
```
**Status:** COMPLETE - All steps wired end-to-end

### Flow 2: Batch Generation & Triage ✓
```
User clicks "Generate Batch" → Ensure DB connected →
Load items from Zotero → Generate batch (with scoring if profile exists) →
Render cards with validation badges → User takes actions (Accept/Reject/Defer) →
Registry updated → Learning triggered (if profile) → Session tracked →
Batch complete → Next batch option
```
**Status:** COMPLETE - Full workflow operational

### Flow 3: Accept Item with Quality Gate ✓
```
User clicks "Accept" → Validation check →
If invalid: Override modal shows missing fields → User confirms/cancels →
If confirmed OR valid: Create note → Mark imported in registry →
Update card badge → Trigger adaptive learning → Record session stat →
Show undo notice → Refresh view
```
**Status:** COMPLETE - Quality gates enforced, override available

### Flow 4: Single Item Import (Command) ✓
```
Command palette: "Import Zotero item" → Check DB configured →
Load items with progress → Search modal opens → User selects item →
Preview modal shows metadata → User confirms → Note created →
Registry marked → File opens in editor
```
**Status:** COMPLETE - Full command flow working

### Flow 5: Adaptive Learning Loop ✓
```
User accepts/rejects items → BatchService.recordAccept/Reject() →
AdaptiveLearner adjusts signal weights (+0.2 for accept, -0.1 for reject) →
ProfileService persists updated profile →
Next batch generation uses updated weights
```
**Status:** COMPLETE - Learning refinement operational

### Flow 6: Error Recovery ✓
```
Operation fails (DB locked, connection error, etc.) →
Retry handler attempts with exponential backoff →
If all retries fail: getErrorContext() maps error →
ErrorModal displays user-friendly message with actions →
User can retry or cancel
```
**Status:** COMPLETE - Error handling integrated throughout
